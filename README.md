# Case-Battel on GitHub Pages

This branch publishes the GitHub Pages entry URL for the full Case-Battel application.

GitHub Pages serves static files. Accounts, balances, inventory and administration run at https://case-battel-5-83-140-108.sslip.io/ using the existing Worker and D1 database. The entry preserves game hash routes and sends `/admin/` to the administrator sign-in page. No account data or credentials are included in this branch.
